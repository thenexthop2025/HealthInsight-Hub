## 🏗️ 技术栈概览

### 后端
- **框架**: FastAPI 0.104.1
- **语言**: Python 3.9+
- **数据库**: PostgreSQL 15
- **统计库**: Pandas、NumPy、SciPy、Statsmodels
- **存储**: 本地文件系统（默认）

### 前端
- **框架**: React 18
- **语言**: TypeScript 4.9
- **UI库**: Ant Design 5
- **图表**: ECharts 5
- **状态管理**: React Query

### 基础设施
- **容器**: Docker + Docker Compose
- **前端静态服务**: Nginx（容器内）

## 🔍 核心功能模块

### 数据管理
- 上传数据（CSV/Excel/SPSS/Stata/SAS）
- 数据预览和列信息查看
- 数据集管理（CRUD）

### 数据预处理
- 数据质量检查（缺失值、异常值）
- 数据清洗（填充、删除、转换）
- 描述性统计
- 正态性检验

### 统计分析（13种方法）
1. 描述性统计
2. 频率分析
3. 探索性数据分析
4. 交叉表分析
5. 卡方检验
6. 相关性分析
7. 线性回归
8. 逻辑回归（二分类）
9. 无序多分类逻辑回归
10. 有序多分类逻辑回归
11. 条件逻辑回归
12. 分层分析
13. 孟德尔随机化

### 报告生成
- PDF报告（自动生成）
- Word报告（可编辑）
- 自定义报告模板
